# ByeLui — Public Website

Public landing page and privacy-policy hosting for **ByeLui**, a free Android expense tracker designed to make personal and household spending easier to record separately.

## What ByeLui offers

- Quick everyday expense tracking with separate **Personal** and **Family** views
- Monthly budgets, analytics, categories and tags
- Recurring expenses and credit-card statement reminders
- Receipt photos, CSV/Excel/PDF exports and portable ZIP backup
- English and Simplified Chinese
- Free to use, with a small Google AdMob banner and no subscriptions

**Current release status:** Android **closed testing**. Not publicly available on Google Play yet.

## Website

- `index.html` — landing page with an invitation to join closed testing via email
- `policy.html` — app privacy policy

The landing page intentionally **does not** present a public Google Play installation link until the app is released. When closed testing becomes public availability, replace the email-based tester invitation with the verified Play listing URL.

## Before public launch

- Test the mobile landing page and verify the email invitation works.
- Confirm every advertised feature is present in the release build.
- Review the privacy policy and replace any publisher placeholder with the correct developer/publisher name.
- Add real screenshots from the current release version when available (none are bundled here).
- Once Play production is approved, update the CTA to the actual Google Play listing.

The app source code is maintained separately in the private development workflow; this repository is the **public promotional website**, not an APK/AAB download site.
